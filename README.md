# Nebula 🌌

یک تجربه تعاملی و خفن با Canvas.

ذرات نئونی، گرانش ماوس، دنباله‌های نورانی و حس فضایی.

**ساخته شده توسط امیرحسین بخشی**

## اجرا

```bash
npm install
npm run dev
```

بعد برو روی [http://localhost:3000](http://localhost:3000)

## کنترل‌ها

- حرکت ماوس / لمس → ذرات جذب می‌شن و منفجر می‌شن
- دکمه «پاک کردن» → همه ذرات پاک می‌شن

## تکنولوژی

- Next.js 14
- Canvas API
- TypeScript
- صفر dependency اضافه
